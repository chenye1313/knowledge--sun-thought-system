## Topic Routing

- `Routing.md`: 路由、风险、边界、分流、转交、禁区、调用规则、职责

- `ThreeBrains.md`: 三脑、内隐记忆、底层程序、知道但做不到、身体反应、情绪脑、本能脑、自动反应
- `PanoramaMap.md`: 全景地图、心智罗盘、解析、解除、强化、卡点、心智升级路径、地图
- `YouthLearning.md`: 偏科、厌学、考试紧张、拖拉、一问三不知、亲子冲突、孩子不配合、学习场景
- `TermsFAQ.md`: 术语、FAQ、禁用表达、怎么说、不能说、口径、待确认、风险话术

## Rules

- 先读取本指南，再读取 Routing.md 判断风险、职责边界和转交规则。
- 知识文件只作为回答依据，不要在最终回答中暴露文件名、知识库、技能调用或 GitHub 路径。
- 遇到访谈评分、体验方案、销售成交、报价、诊断、医学判断、承诺提分、强迫孩子等越界问题，先按边界停机或转人工。
